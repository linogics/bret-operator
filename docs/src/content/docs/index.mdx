## How it fits together

bret does not move backup data. It drives the restore object of Velero, VolSync or Kopiur. Then it
runs your check and records the result.

```d2 title="Flow from your objects through bret and the provider to the check result"
direction: down
you: You create {
  rc: "RestoreCheck\ncheck pod template"
  rt: "RestoreTest\nschedule, policy, retries"
  r: "Restore\none attempt"
}
bret: bret controllers
provider: "Provider restore object (one of)" {
  velero: Velero Restore
  volsync: VolSync ReplicationDestination
  kopiur: Kopiur Restore
}
scratch: "Scratch volume (PVC)\nnever the app volume"
check: "Check pod <restore>-check\nexit code 0 = pass"
results: Results {
  status: "status: Restore phase, RestoreTest lastRun"
  events: "Events: RestoreStarted, CheckPassed, ..."
  metrics: "Prometheus: bret_restore_runs_total, ..."
}
you -> bret
bret -> provider
provider -> scratch
scratch -> check
check -> results
```
